# G-SS

> A custom styling language designed to feel like CSS while fitting naturally into the Zoom Studios toolchain.

## Overview
G-SS is a custom language built to mirror the logic and structure of CSS. It preserves the familiar styling workflow of selectors, properties, and rule cascading, making it easy for developers to transition into a more custom ecosystem.

## Core Philosophy
- Matches the styling logic of traditional CSS
- Supports familiar property definitions and cascading rules
- Works smoothly with G-HTML, G-Sharp, CS, GS, and visual block systems

## Why It Feels Familiar
If you know CSS, you will quickly recognize the structure of G-SS. It is designed to be practical, readable, and easy to adopt for anyone already comfortable with modern web styling.
