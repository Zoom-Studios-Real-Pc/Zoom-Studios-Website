# G-finity

> A custom game engine built for performance, independence, and creative freedom.

## Overview
G-finity is a fully custom game engine created from the ground up. It is designed to be flexible, efficient, and self-contained, with its own rendering, physics, and core game logic systems rather than relying on external engine frameworks.

## Core Architecture
- Built from scratch with custom memory handling, rendering pipelines, and asset processing
- Supports game development through CSS, GSS, CS, and GS
- Allows visual scripting through blocks for game logic and mechanics
- Operates independently without reliance on proprietary third-party engine runtimes

## Why It Stands Out
G-finity is focused on giving developers a strong and original foundation for building games with control, performance, and a distinctive architecture.
