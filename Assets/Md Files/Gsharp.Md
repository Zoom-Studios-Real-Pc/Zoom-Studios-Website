# G-Sharp

> A custom language designed to feel familiar to C# developers while fitting naturally into the Zoom Studios ecosystem.

## Overview
G-Sharp is built to mirror the strengths of C# with object-oriented structure, clear syntax, and strong typing. It gives developers a familiar programming experience while remaining part of a larger custom toolchain.

## Core Philosophy
- Reflects the core logic and structure of C#
- Supports classes, methods, and object-oriented design patterns
- Integrates smoothly with CSS, GSS, CS, GS, G-HTML, and visual blocks

## Why It Feels Natural
If you already know C#, the transition to G-Sharp should feel intuitive. It is designed to preserve the familiar style of modern object-oriented programming while staying flexible and custom-built.
