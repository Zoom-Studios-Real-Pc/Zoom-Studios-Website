# G

> A custom programming language designed to feel familiar to C developers while fitting naturally into the Zoom Studios ecosystem.

## Overview
G is a custom language modeled on the structure and logic of C. It brings the same procedural thinking, low-level control, and straightforward syntax that C developers expect, making it easy to learn and use within a broader custom development environment.

## Core Philosophy
- Built around the same procedural principles as C
- Supports pointer-based logic and low-level programming concepts
- Designed to work smoothly alongside G-Sharp, G-SS, G-HTML, GS, and visual block systems

## Why It Works
If you already know C, you will quickly recognize the flow and structure of G. It is meant to feel natural, efficient, and approachable for experienced developers.
